# Recursos visuais e sonoros

`substitution_log.png`: tronco fotorealista com transparência, criado com
ImageGen para esta versão. A silhueta quase vertical e os dois galhos quebrados
são inspirados no tronco do jutsu de substituição de Naruto.
A casca, os anéis e a iluminação pertencem à imagem;
a queda, o ajuste de exposição e a sombra são calculados pelo programa.

Prompt de criação: tronco de substituição de Naruto como objeto real;
cilindro curto e espesso quase vertical, leve inclinação, dois pequenos galhos
quebrados em lados opostos, casca marrom rugosa e corte superior com anéis de
crescimento, luz suave e fundo transparente.

Prompt da edição final: preservar o tronco, galhos, casca, anéis, cores e
perspectiva; remover fundo, névoa, brilho e sombra externa; manter o objeto
inteiro, inclusive a base, com transparência real, sem textos ou logotipos.

`smoke_cloud.png`: nuvem de fumaça realista com transparência criada com
ImageGen para este projeto. `realistic_smoke.py` transforma a textura em
camadas animadas com expansão, fluxo turbulento e dissipação. Não é uma
simulação física 3D. As cores são pré-multiplicadas pelo alfa antes de qualquer
redimensionamento para evitar bordas escuras.

`gestos-ninja.svg`: guia vetorial das poses de mãos adaptadas ao reconhecimento
pela webcam.

Os arquivos de identidade visual foram criados para PeraVanishCam.
`vanish.MP3` e os recursos herdados mantêm os créditos da base; veja
[ORIGEM.md](../ORIGEM.md).
